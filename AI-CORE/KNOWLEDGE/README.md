# Knowledge

Dauerhaft nützliches, projektübergreifendes Wissen als Markdown (eine Datei pro Thema, Dateiname = Thema).
Suche: Claude Code durchsucht die Dateien direkt (Grep) — das reicht für Hunderte Dokumente.

Konventionen: oben `Source:` und `Last verified: YYYY-MM-DD`; Fakten mit Quelle; kein Projektwissen (gehört ins Projekt).
