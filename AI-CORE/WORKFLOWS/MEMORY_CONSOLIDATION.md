# Memory Consolidation

Rhythmus: monatlich, oder wenn `python SCRIPTS/core.py check` Memory-Hinweise meldet.

1. **Abgelaufener Kontext** (`BRAIN/CONTEXT.md`): löschen oder — falls dauerhaft relevant — in die passende Datei verschieben.
2. **Duplikate:** gleiche Aussage in mehreren Dateien → eine Stelle behalten, andere verlinken/entfernen.
3. **Widersprüche:** neuere, vom Nutzer bestätigte Aussage gewinnt; bei Zweifel nachfragen.
4. **Veraltetes:** Ziele erreicht/aufgegeben, Tools gewechselt → aktualisieren; Historisches nach `ARCHIVE/memory/`.
5. **"(Quelle: abgeleitet)"-Einträge:** bestätigen lassen oder entfernen.
6. **Learnings:** ähnliche zusammenfassen; nicht mehr handlungsrelevante archivieren.
7. **Größe:** jede BRAIN-Datei < 200 Zeilen.

Ausgabe: Änderungsvorschlag als Liste (alt → neu). **Änderungen erst nach Bestätigung**, danach Git-Commit
"memory: consolidation YYYY-MM", damit alles nachvollziehbar und umkehrbar ist.
